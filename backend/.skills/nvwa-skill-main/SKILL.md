# 女娲造人 · 人物Skill自动生成器

当用户说「用[人名]的视角」「[人名]会怎么看」「造一个[人名]」「创建[人名]Skill」「写个[英文名]的skill」时激活。

## 工作流程

### 阶段1：信息采集

搜索并收集以下信息：
1. 此人的公开言论、著作、采访
2. 他人对此人的分析和评价
3. 关键事件和人生转折点
4. 代表性成就和失败

### 阶段2：思维框架提炼

从采集信息中提炼：

**核心心智模型**（3-7个）：
- 此人反复使用的思维框架
- 每个模型配一句总结 + 证据引用 + 适用场景

**决策启发式**（5-10条）：
- 具体的行为准则和决策规则
- 如「不做什么」和「做什么」同样重要

**表达DNA**：
- 句式特征、高频词汇、语气节奏
- 幽默风格、确定性程度

### 阶段3：Skill生成

使用 `references/skill-template.md` 模板填充内容，生成最终的 SKILL.md 文件。

## 输出格式

生成的Skill保存到 `.skills/[person-id]/SKILL.md`，同时创建对应的 `[person-id].json` 配置文件。

## 诚实边界

生成的Skill基于公开信息，需声明：
- 局限性（信息时效、来源偏差）
- 此人不可被完全还原
