# 拖拽文件/文件夹到侧边栏资源管理器

## 概述

支持从 Windows 资源管理器直接拖拽文件或文件夹到左侧 Sidebar，释放后自动打开该文件夹作为项目。

## 原理

- Electron 环境下，`event.dataTransfer.files[0]` 的 File 对象含扩展属性 `.path`，可直接获取完整系统路径（如 `C:/Users/xxx/projects/my-app`）
- 该路径可直接复用现有 `onSelectProject(path)` 流程 → 后端 `_resolve_path` 做权限边界检查 → 目录树渲染

## 实现量

| 文件 | 改动 |
|---|---|
| `ProjectExplorer.tsx` | 添加 onDragOver/onDrop 事件处理 + 拖拽高亮 + `.path` 读取 + 浏览器回退 |

核心代码约 20 行，App.tsx 及后端无需改动。

## 注意事项

- 仅 Electron 有效，浏览器无 `.path` 属性
- 拖入单个文件时自动定位到其父目录
- 拖拽过程中侧边栏需有高亮边界提示
- 受 contextIsolation 保护，路径最终经后端权限校验
